# Evaluation task files

One JSON object per line: `{"id": ..., "group": <involved API classes>, "turns": N}`.
Generated by `eval/make_tasks.py` (stratified by API group, fixed seed). Never edit by hand.

| File | Purpose | Command |
|---|---|---|
| `pilot.jsonl` | Pilot: measure tokens per task, choose the sample size, noise check | `python eval/make_tasks.py pilot --n 10 --seed 1` |
| `dev.jsonl` | Tuning set for contributions (C1 retriever/k, C2 thresholds, ...) | `python eval/make_tasks.py dev --n 30 --seed 3` |
| `frozen_sample.jsonl` | **Frozen** test sample for every config. Never tune on it. Excludes pilot + dev. | written after the pilot |

Always excluded from both: the Phase 1 dev smoke tasks (`multi_turn_base_3`, `_17`, `_100`) and
the live-demo presets (`_50`, `_100`, `_132`, `_182`). The frozen sample also excludes the
pilot. C3 plan-cache warm-up tasks (Phase 7) must come from what's left.
